# Bog Standard 0.12.1

Walking-skeleton MVP for epic E013.

- Jakarta servlet WAR at `/bogstandard`
- PostgreSQL 16 schema auto-applied on boot
- Registration, verify, login, password reset
- Venue / facility / amenity model with per-type ratings
- Leaflet map, nearest (geolocation), postcodes.io search, filters + open-now
- Reviews, submissions, admin queues, reports
- PWA shell, branded mail templates
- Gloucestershire seed (unverified)

Repo: https://github.com/TheChrisJMartin/BogStandard
